# Study MBBS Abroad - Landing Page

## Project Overview
This project is a landing page for students interested in applying for MBBS programs abroad. It features an interactive hero section, information about top countries, admission process details, and an application form. The form submission includes validation with Toastify notifications.

## Features
- **Hero Section** with background image and overlay
- **Why Study MBBS Abroad?** section with key benefits
- **Top Countries** grid display
- **Admission Process & Eligibility** section
- **Apply Now Form** with input validation and success/error notifications
- **Google Analytics & Facebook Pixel** integration for tracking
- **Tailwind CSS** for styling
- **Toastify.js** for user notifications

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Toastify.js
- Google Analytics
- Facebook Pixel

## How It Works
1. Users land on the homepage and see the hero section.
2. Clicking the "Apply Now" button scrolls down and reveals the form.
3. The form includes fields for **name, email, phone, and preferred country**.
4. Upon submission:
   - If any field is empty, a **red error notification** appears.
   - If all fields are correctly filled, a **green success notification** appears, and the form resets.

## Setup & Installation
1. Clone the repository or download the files.
2. Open `index.html` in a browser.
3. Ensure an internet connection for external scripts (Tailwind CSS, Toastify.js).
4. Modify `script.js` if needed for additional functionality.
